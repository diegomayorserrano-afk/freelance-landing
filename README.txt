
# Blog estático incluido (v3)

Este paquete incluye `index.html`, `mc-logo.svg` y una carpeta `blog/` con 4 artículos:
- `blog/due-diligence.html`
- `blog/breakeven-canales.html`
- `blog/plan-90-dias-aperturas.html`
- `blog/retener-talento-sin-coste.html`

## Cómo subirlo
1) Sube **todos** los archivos y carpetas al directorio raíz de tu hosting (public_html o www).
2) Asegúrate de mantener la **carpeta `blog/`** al mismo nivel que `index.html`.
3) Abre tu dominio en el navegador. Las tarjetas del blog ya no darán 404.

Open Graph listo (v5)
- Cambia en `index.html` el campo `og:url` por tu dominio real (ej.: https://mayorconsulting.com/).
